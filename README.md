# THC_challenge

This repository presents CTF (Capture The Flag) challenges. In a CTF, the goal of the participant is to exploit one or more computer vulnerabilities in order to obtain a flag that validates the completion of the challenge. The flag is usually a password with a specific format. We introduce 3 different challenges varying greatly in the way to obtain the flag. Each challenge is described in its own README with the soluce given. Also, you can find a complete report in "rapport/rapport.pdf".
